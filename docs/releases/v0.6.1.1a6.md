# AetnaMem 0.6.1.1a6 — focused dashboard memory search

Status: **experimental preview**

Dashboard search now shows the smallest useful matching sentence or bullet
instead of rendering the complete indexed source chunk.

For example, searching for `kebab` in a chunk that also contains car and fruit
preferences returns:

```text
JT said they like kebab for food.
```

The memory plane, source path, and line range remain visible underneath. The
canonical stored content is unchanged and remains available for audit and
exact reads.

Search results are capped at 12 items in the dashboard. This changes only the
investigator display; it does not change agent recall ranking, storage,
deletion, provenance, or the audit chain.

## Update

```bash
python -m pip install --upgrade --pre aetnamem==0.6.1.1a6
aetnamem dashboard daemon restart
```

The compatible npm bridge remains
`openclaw-memory-aetnamem@0.4.1-experimental.3`.
