# AetnaMem 1.0.0a1 — one memory control plane

Status: **experimental prerelease**

AetnaMem 1.0 removes unrelated product experiments and presents one coherent product:

> AetnaMem’s memory engine is model-agnostic, but its complete reversible memory switch is currently OpenClaw-specific.

## What ships

- Python package `aetnamem==1.0.0a1` with one `aetnamem` CLI;
- OpenClaw bridge `openclaw-memory-aetnamem@1.0.0-experimental.1`;
- complete historical copy and ongoing shadow of native OpenClaw memory;
- verified activation that replaces native supplemental memory with AetnaMem;
- verified restore to the saved OpenClaw state;
- dashboard for mirror status, search, approvals, audit investigation and export;
- model-agnostic Python and MCP memory interfaces;
- canonical SQLite memory, provenance, deletion receipts and optional semantic search;
- typed, quarantined text observations of host-controlled media.

## Removed from the 1.0 product

Unrelated legacy experiments are not shipped. Their Git history is preserved; they are not part of the product claim.

## Install

```bash
python -m pip install --pre aetnamem==1.0.0a1
aetnamem openclaw install
aetnamem dashboard daemon start
```

This prerelease is intended for controlled local evaluation. Validate shadow copy, search and restore on representative OpenClaw workspaces before relying on active mode.
