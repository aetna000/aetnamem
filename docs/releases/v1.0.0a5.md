# AetnaMem 1.0.0a5 — reliable OpenClaw installation

Status: **experimental prerelease**

AetnaMem 1.0.0a5 fixes a real installation failure discovered against OpenClaw 2026.7.1-2. The previous installer correctly wrote the control-plane configuration, but then rejected OpenClaw's schema-expanded response and rolled the installation back.

## What changed

- The installer now verifies the configuration fields AetnaMem owns instead of requiring the entire OpenClaw object to be byte-for-byte identical.
- OpenClaw may retain additional schema defaults without causing a false installation failure.
- Agent Black Box recording is explicitly enabled during the verified installation flow.
- The integration test now reproduces OpenClaw's default expansion so this regression cannot be hidden by a simplified mock.

## Real-host verification

The repaired installer was exercised against OpenClaw 2026.7.1-2 before release. All eight installation stages completed, including gateway restart, runtime-hook verification, native-memory baseline capture, searchable mirroring and audit-chain verification.

The complete Python suite also passed with 198 tests.

## Install or upgrade

Do not install the npm bridge separately. The Python installer pins and verifies the matching OpenClaw integration.

```bash
python -m pip install --upgrade --pre aetnamem==1.0.0a5
aetnamem --version
aetnamem openclaw install
```

Packages:

- Python: `aetnamem==1.0.0a5`
- OpenClaw bridge: `openclaw-memory-aetnamem@1.0.0-experimental.5`

## Claim boundary

This release fixes installation and explicitly enables the experimental Agent Black Box. Its verification claim is unchanged: a verified flight proves retained timeline integrity and observed hook closure. It does not prove an external real-world outcome or semantically validate an agent response.
