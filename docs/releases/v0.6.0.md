# AetnaMem 0.6.0 — Memory Impact Lab

Status: **public experiment infrastructure; no causal product result claimed**

> **AetnaMem remembers whether remembering actually helped.**

Version 0.6.0 turns the default-off Causal Memory Ledger foundation into a
complete, reproducible **Memory Impact Lab**. It can precommit all 16
working/semantic/episodic/procedural combinations, run an isolated reference
agent, verify the result outside the agent process, and preserve signed
evidence for independent checking.

## Added

- `aetnamem impact init`, `run`, `verify`, and `report`;
- a 24-task starter suite covering single-plane, interaction, all-four, null
  and harmful-memory cases across train, validation and held-out splits;
- randomized-without-replacement 16-arm schedules inside every task block;
- run-ID-bound assignment tokens and seed/schedule commitments;
- exact final exposure spans and fail-closed benchmark truncation;
- deterministic candidate identities across cloned snapshots;
- fresh SQLite and workspace clones per run;
- Grok CLI binary/model/control metrology;
- an MCP profile exposing no memory or outcome tools to the experimental agent;
- signed host outcome receipts bound to manifests and verifier artifacts;
- repeated planted-effect calibration with direction, coverage and null gates;
- ITT main effects, pairwise interactions, arm rates, cost, token and latency reports;
- a policy frozen from training evidence before held-out execution;
- a one-call paid Grok smoke gate that proves the registered invocation can
  edit its isolated workspace before a full training block starts;
- host-verified AetnaMem context-character accounting for policy budgets,
  separate from provider tokens that may include system prompts and cache
  reads.

## Compatibility

Install remains:

```bash
pip install aetnamem
```

The original Python `Memory` API, 17 generic MCP tools, four-memory presets,
Bernoulli shadow/benchmark behavior, SQLite data, audit search, semantic
investigator sidecar, multimodal observations and CLI commands remain
compatible. All normal presets still set CML to `off`.

OpenClaw plugin `0.3.1` ships alongside Python `0.6.0`. Its hook and tool
contracts are unchanged by the host-side Memory Impact infrastructure, but
this release publishes the already-versioned package because the public npm
registry previously stopped at `0.2.4`.

## Use with Grok CLI

```bash
python3 -m pip install --upgrade aetnamem
aetnamem setup --yes --preset starter --subject you \
  --agent grok-primary --skill-path ~/.grok/skills
grok mcp add --scope user aetnamem -- \
  aetnamem runtime mcp --config ~/.aetnamem/runtime.json
grok mcp doctor
```

This enables the normal bounded four-memory runtime and leaves experimental
withholding off. It makes governed context available to Grok; it does not
guarantee improvement. See the [Grok/xAI guide](../grok-xai.md) and the
[plain-language X article](../marketing/x-memory-impact-v0.6.0.md).

## Scientific boundary

This release implements every phase of the experimental workflow and includes
a paid **exploratory** Grok pilot. It does not contain a complete confirmatory
Grok result: the registered schedule was deliberately capped at 100 calls and
the frozen-policy held-out phase was not run. A product benefit claim still
requires completion of the registered experiment, a held-out win under the
same budget, and replication.

## Release validation

- Python suite: **226 passed, 4 skipped**.
- OpenClaw npm 0.3.1: type-check, setup/hook tests and build passed unchanged.
- Python 0.6.0 wheel and source archive built; an isolated installed-wheel smoke
  test passed.
- The packaged CLI completed `impact init`, the full synthetic gate, a
  fake-agent 16-arm train/held-out controller run, independent verification and
  HTML report generation.
- The registered 500-simulation calibration passed with 0.0272 mean absolute
  error, 0.936–0.950 interval coverage, 0.064 null false-positive rate and
  0.982–1.000 empirical detection power at 80 blocks.
- Local Grok metrology pinned `grok 0.2.111 (94172f2aa4e5)` and executable
  SHA-256 `e1fafdfffe14f339460befaf194360e8f90bfd02efe8a4f24cfa1c7aea657ffe`.
- A paid starter attempt stopped after 256 training/validation calls because
  `dontAsk` cancelled the registered workspace edits. All 256 receipts and
  schedule/seed bindings verified, but all host outcomes failed and 128
  held-out receipts are intentionally missing. The run therefore supports no
  memory-impact claim. The corrected one-call smoke then received
  `402 Payment Required` because the Grok balance was exhausted.
- After replenishment, the corrected smoke passed and a deliberately capped
  recovery pilot completed 100 verified receipts with zero aborts, 57
  successes, six complete balanced blocks and USD 8.3339928 experimental cost
  plus a USD 0.016532 smoke. The all-four arm was 6/6 and no-memory was 1/6,
  but the schedule remains incomplete and no held-out claim is made.
