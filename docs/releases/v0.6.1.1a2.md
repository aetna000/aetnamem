# AetnaMem 0.6.1.1a2 — mirror first, switch after proof

Status: **experimental prerelease**

AetnaMem can now sit beside a local OpenClaw installation, mirror its native
memory without changing prompts, and provide a reversible takeover after the
user reviews the evidence.

Matching packages:

- Python: `aetnamem==0.6.1.1a2`
- OpenClaw bridge: `openclaw-memory-aetnamem@0.4.1-experimental.2`

Customers install only through the Python-owned flow:

```bash
python -m pip install --pre aetnamem==0.6.1.1a2
aetnamem --version
aetnamem openclaw install
```

The installer obtains and verifies the matching npm bridge internally.

## What changed

- Takes a verified byte-for-byte pre-shadow baseline of every recognized
  persistent native memory source: `MEMORY.md`, `memory/`, `USER.md`, pinned
  workspace instructions and workspace skills, including non-Markdown files
  and empty directories.
- Mirrors searchable OpenClaw Markdown memory into an isolated AetnaMem SQLite
  database with source path, file digest and line provenance, while retaining
  observed native-state versions during shadowing.
- Computes silent shadow recall without changing model context or making an
  extra provider call.
- Adds human-readable `aetnamem openclaw memory status|sync|search|trace`.
- Adds the authenticated dashboard at `aetnamem dashboard`.
- Adds detached dashboard lifecycle commands:
  `daemon start|stop|restart|status|remove`.
- Adds an explicit activation ceremony that checkpoints the mirror, creates
  and verifies a second complete switch-time snapshot, disables duplicate native recall/writing,
  applies bounded AetnaMem recall, restarts OpenClaw and verifies the gateway.
- Adds exact rollback for native files, memory slot, session hook and plugin
  configuration.
- Keeps OpenClaw identity, safety, authorization, tools and executable skills
  pinned.

## Why

The prior preview could observe AetnaMem but did not honestly replace
OpenClaw's native memory. That meant active mode could duplicate memory and
could not support a clear “AetnaMem is now the memory system” statement.
This prerelease makes the boundary concrete and reversible.

## Honest measurement boundary

The dashboard reports verified mirror/audit/cutover state and a
context-budget projection. It does not claim guaranteed token savings. A
small native memory may show no expected reduction; actual provider cost and
task success still require observed host metrics.

## Rollback boundary

Activation does not discard native memory. AetnaMem retains both the
pre-shadow baseline and a complete switch-time snapshot. It refuses cutover if
the source changes during copying or any byte digest differs.
`aetnamem trial rollback` restores and re-verifies the switch-time tree and
the prior OpenClaw configuration. Trial evidence, past model outputs and
provider logs are preserved.
