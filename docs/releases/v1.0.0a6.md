# AetnaMem 1.0.0a6 — idempotent OpenClaw installation

Status: **experimental prerelease**

AetnaMem 1.0.0a6 makes `aetnamem openclaw install` safe to rerun. If the same OpenClaw migration is already shadowing, the installer now refreshes and verifies it instead of failing because the control ID already exists.

## What changed

- Reuses an existing shadow migration for the same OpenClaw host.
- Refreshes the complete native-memory mirror and re-verifies the gateway, plugin hooks, baseline and audit evidence.
- Keeps the same control ID instead of creating a competing migration.
- Preserves the original pre-AetnaMem restore snapshot byte-for-byte.
- Repairs the managed plugin configuration without replacing the restore baseline.
- Reports `existing shadow verified` in human-readable output and `existing_migration_reused: true` in JSON output.
- Still refuses unsafe state changes: an active migration is not silently downgraded or replaced.

## Install or rerun safely

```bash
python -m pip install --upgrade --pre aetnamem==1.0.0a6
aetnamem openclaw install
```

Running the install command again is now a supported verification and repair operation:

```text
[############--------] 5/8  Refreshing the existing OpenClaw memory mirror
...
Installation           existing shadow verified
```

Packages:

- Python: `aetnamem==1.0.0a6`
- OpenClaw bridge: `openclaw-memory-aetnamem@1.0.0-experimental.6`
