# AetnaMem 1.0.0a2 — direct local dashboard access

Status: **experimental prerelease**

This release removes dashboard login codes, session cookies and authentication redirects. The dashboard now opens directly at:

```text
http://127.0.0.1:8766/
```

The daemon stores and opens that stable loopback URL. Restarts and refreshes can no longer fail because a code was consumed, expired or replaced.

The network boundary remains local-only: the server rejects non-loopback bindings and invalid Host headers. State-changing requests still require a same-origin request and the dashboard's CSRF token.

Packages:

- Python: `aetnamem==1.0.0a2`
- OpenClaw bridge: `openclaw-memory-aetnamem@1.0.0-experimental.2`

```bash
python -m pip install --pre aetnamem==1.0.0a2
aetnamem openclaw install
aetnamem dashboard daemon start
```
