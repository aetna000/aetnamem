# AetnaMem 1.0.0a4 — experimental Agent Black Box for OpenClaw

Status: **experimental prerelease**

AetnaMem 1.0.0a4 adds a content-minimizing flight recorder for OpenClaw agent runs. It lets an operator inspect the lifecycle the host actually observed instead of relying only on what the assistant said happened.

## What changed

- Records model-input/output fingerprints, context preparation/injection, tool requests/completions and turn termination through documented OpenClaw hooks.
- Stores SHA-256 digests and bounded metadata rather than raw prompts, responses, tool parameters or tool results; derived paths are hashed before recording.
- Adds a migration-scoped, tamper-evident Agent Black Box evidence chain.
- Detects missing tool completions, orphan completions, tool errors, absent terminal events and evidence-chain tampering without converting those gaps into success claims.
- Adds `aetnamem blackbox status`, `runs`, `show`, `verify` and JSON/text `export` commands.
- Adds a dashboard flight list and drill-down timeline with coverage, tool closure, claim boundary and downloadable reports.
- Strengthens the reversible OpenClaw control plane with journaled restoration evidence, a non-destructive restore drill and read-only control verification.

## Claim boundary

A verified flight proves retained timeline integrity and observed hook closure. It does not prove that an external real-world outcome occurred, and it does not semantically validate claims in the agent response. A completed tool hook is host evidence, not a receipt from the external system the tool contacted.

At-rest encryption is not claimed in this release. Key resolution, household policy and locking foundations exist for later work, but database/archive encryption and migration are not shipped.

## Install

Do not install the npm bridge separately. The Python installer pins and verifies the matching OpenClaw integration.

```bash
python -m pip install --pre aetnamem==1.0.0a4
aetnamem --version
aetnamem openclaw install
aetnamem dashboard daemon start
```

Packages:

- Python: `aetnamem==1.0.0a4`
- OpenClaw bridge: `openclaw-memory-aetnamem@1.0.0-experimental.4`

## Verify the release

The release is gated by the complete Python suite, installed-wheel smoke checks, TypeScript type checks, OpenClaw hook integration tests, npm package checks and distribution validation. Black Box tests cover complete flights, missing completions, raw-field rejection, chain tampering, dashboard endpoints and absence of raw test content in retained evidence.
